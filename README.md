# Heatwave Watch India + PostgreSQL
1. Open `db.js` and put your Postgres password in.
2. pgAdmin: open the `heatwave` database > Query Tool > paste `schema.sql` > run (F5).
3. Terminal in this folder: `npm install`, then `npm run seed`, then `npm start`.
4. Open http://localhost:3000
=======
# Heatwave-Tracking-System
An interactive heatwave-risk monitoring prototype for Indian weather stations that uses machine-learning models to estimate 5-day-ahead heatwave risk, visualize temperature forecasts, and generate automated alerts using PostgreSQL, Node.js, and an interactive dashboard. Built using synthetic data for demonstration purposes.
